# License Lens · 依赖许可证审查台

纯前端的 npm 依赖许可证审查工具：粘贴或导入 `package-lock.json`，按包名、版本、安装路径整理直接与传递依赖，依据分发方式（闭源交付 / 开源分发）给出放行结论，并保留人工处理记录。

## 使用

```bash
npm install
npm run dev      # 本地开发
npm run build    # 类型检查 + 产物构建
```

## 审查规则

- **闭源交付**：GPL / AGPL 等强 Copyleft 组件阻止放行（含传递依赖、dev 作用域会降级为复核）；LGPL / MPL 等弱 Copyleft、CC-BY-SA、受限商业许可进入复核；许可证缺失或无法识别一律进入复核。
- **开源分发**：强 Copyleft 可通过（提示源代码开放义务）；未知 / 专有许可证仍需复核。
- 支持 SPDX 表达式：`AND` 取最严、`OR` 取最宽、识别括号与 `WITH` 例外条款。
- 放行闸门始终针对完整清单；列表与统计跟随当前筛选 / 搜索结果。

## 功能

- 支持 lockfileVersion 1 / 2 / 3；同名多版本按安装路径区分，依赖图按 npm 逐级向上解析规则重建。
- 点击任意包查看从项目根出发的完整引用链（含直接 / 传递、dev、可选边标记）。
- 人工处理结论（沿用自动判定 / 人工通过 / 转复核 / 人工阻止 + 备注）按 `name@version` 归档，作用于该版本全部路径。
- 分发方式、处理结论、导入的清单文本均存于 localStorage，关闭页面后再打开仍在；可一键重置。
- 导出 Markdown 审查报告。

## 代码结构（解析、判断、页面分离）

| 模块 | 职责 |
| --- | --- |
| `src/lib/parse-lockfile.ts` | 解析层：lockfile → 包节点（名称/版本/路径/作用域/直接或传递）与依赖边，不含任何好坏判断 |
| `src/lib/policy.ts` | 判断层：许可证归类、SPDX 表达式求值、按分发方式判定、闸门汇总（纯函数） |
| `src/lib/chains.ts` | 引用链：在依赖图上反向遍历出根 → 目标的完整路径 |
| `src/lib/persistence.ts` | 持久化：唯一接触 localStorage 的模块 |
| `src/lib/types.ts` | 各层共享的数据契约 |
| `src/App.tsx` / `src/styles.css` | 页面层：导入、列表、统计、闸门、详情抽屉 |

> 工具结论仅用于初筛，发版前请让法务 / 合规复核。
